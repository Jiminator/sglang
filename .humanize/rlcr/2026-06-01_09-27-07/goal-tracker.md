## IMMUTABLE SECTION
<!-- Do not modify after initialization -->

### Ultimate Goal

Close — or rigorously characterize — the DeepSeek-V3.2 (DSv3.2) FP8 **double-sparsity (DS) long-context recall gap**. Today DS recalls **4K 75% / 16K 5% / 64K 0%** (NIAH) against DSA's **100% at every length using the same 2048 selection budget and the same decode kernel**. This is the deferred, high-priority Tier-2 recall carryover from Loop 6, gated-open by `runs/20260530_dsv32_loop6/ds_on_v32_decision.md`.

The work is **diagnosis-led**: an instrumented oracle first measures *why* DS misses the needle — *budget-limited* (the 2048 cap is the wall) or *scorer-limited* (DS picks the wrong 2048). Evidence already leans scorer-limited (at 4K, DS selects ~50% of tokens yet misses 25% of needles). The plan **measures first, leads with the cheap selector improvement (Tier-2.B), and pursues the heavy adjustable-budget decode kernel (Tier-2.A) only if the diagnostic proves a wider budget recovers recall.** The DSA production default and the Loop-6 Tier-1 operating point are never regressed; all new code is opt-in and reversible. If M0 evidence reverses the gate's Tier-2.A-primary ordering, a decision record **supersedes** the prior ordering by citing what changed.

### Acceptance Criteria
<!-- Each criterion is independently verifiable; full positive/negative tests live in development/loop7/refined_plan_v1.md -->

- **AC-1 — Measure-first oracle diagnostic + separated baseline.** A flag-gated debug-oracle, computed on the live all-reduced token-score tensor (after `all_reduce_token_scores`, before `select_topk_sequence_order`), records per NIAH trial: harness-provided needle span, `needle_worst_rank`, `needle_all_tokens_in_topK`, `selected_contains_needle`, score-only recall@K for K∈{512,1024,2048,4096,8192}, and the sampling stride; invariant `recall@2048 == selected_contains_needle`. Oracle output goes to a dedicated flag-gated sink (NOT `metrics.py::record_selection`). Oracle-off is byte-identical + zero-alloc under graph replay (demonstrated, not asserted). Baseline separates served-recall from admission/HTTP failure at mem 0.7, with a stride=1 dense reference. **AC-1.1**: dense-within-window oracle forces the needle in by post-topK logical-index replacement only (evict lowest-ranked non-needle, insert needle, preserve exactly 2048).
- **AC-2 — Recall uplift measured (DS-vs-DSA, same node).** Floor = recorded+characterized non-regressing result; strict target = stretch. Trial count + Clopper–Pearson binomial CI stated up front; "material" must exceed the baseline CI. A legitimate negative result still closes the loop.
- **AC-3 — Tier-2.B selector uplift (non-learned, flag-gated, non-regression).** Each variant (channel weighting/normalization; head-aggregation; anchor-budget) independently flag-gated; default channel-mask byte-identical when off; NIAH within-budget parity, MMLU ≤1.0pp of a re-anchored op-point DSA baseline, dense-DS 100%, TP=8 cross-rank selected-index equality.
- **AC-4 — Tier-2.A opt-in adjustable-budget decode (only if AC-1 oracle uplift justifies).** New ABI `enable_lifted_budget_decode` + `lifted_budget_top_k` (NOT `max_top_k`/Twilight, NOT `SGLANG_DS_ALLOW_TOPK_MISMATCH`); default DSA `dsa_index_topk` assert untouched; physical→`page_table_1_flattened`→compact remap; pad/`-1` masked before dequant; fixed budget+padding; R23 tie-break; kernel-correctness + prefix-sharing + TP-determinism tests; landed path production-ready (alloc-free dequant `out=`/graph-safe) or deferred-with-evidence.
- **AC-5 — Tier-2.C servability (separated, 64K-first).** 64K `/generate` re-confirmed at mem 0.7 (served vs admission distinct); 128k deferred to its own loop.
- **AC-6 — No Tier-1 regression + perf guardrails.** Loop-6 admission/TTFT spine + directional conc-16 result hold; DSA/fp16 defaults unchanged; TTFT/decode-TPS/mem at conc-1/16 recorded within budget.
