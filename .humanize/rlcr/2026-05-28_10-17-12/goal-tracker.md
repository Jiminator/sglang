## IMMUTABLE SECTION

### Ultimate Goal

Ship a demonstrable Double Sparsity (DS) MVP on DeepSeek-V3.2 (FP8) running end-to-end on the H200 cluster, in two explicit tiers, without conflating a hardware smoke milestone with the loop4-complete MVP.

- **TIER 1 — Smoke MVP:** DS-on V3.2 FP8 serves real requests on H200, produces *genuinely sparse* (non-trivial) DS selection, yields one DS benchmark artifact + one matching DSA benchmark artifact at a clearly-labeled smoke shape, and passes the paired quality smoke. Narrative: "DS-on V3.2 FP8 serves at the locked Option B operating point. Side-by-side with DSA at conc 16/32/64. Quality smoke passes on 20 paired prompts. Here's the bench JSON and the comparator report."
- **TIER 2 — Loop4-compatible MVP:** the smoke milestone plus the loop4 requirements needed to claim comparable default-cookbook behavior: radix cache enabled for the final serving run (AC-10), the AC-11 directional comparator, the AC-12 full quality gate, CUDA-graph status recorded (AC-6), and the chunked-prefill probe run and recorded (AC-1b). Narrative adds: "The final run used matching production knobs, including radix cache enabled; CUDA graph and chunked-prefill status are recorded; AC-11 comparator and AC-12 quality gates are complete."

If AC-10 radix, AC-11 comparator, or AC-12 full quality are missing, the result is a useful smoke milestone, not the minimal viable working version requested by loop4.

**Root blocker (loop 4 never executed against hardware):** the calibration artifact `/models/dsv32-fp8-channel-mask.safetensors` does not exist on disk, and generating it unblocks every DS-on criterion. A second prerequisite is the Round-38 AC-10 producer bug, which must be patched before any radix-on or default-cookbook parity claim.

- **AC-4 (TIER 1):** Calibration load path is native-FP8 device-sharded (no bf16 upcast, no single-device pin). One-block dry-run logs param dtypes + device placement and confirms no upcast BEFORE the full run. `/models/dsv32-fp8-channel-mask.safetensors` produced; `load_channel_mask()` succeeds with `dtype="fp8_e4m3"`, `page_size=64`, `label_dim=16`, `head_dim=128`, `channel_selection` int32 `[L,H,16]`; content SHA recorded; full run does not OOM on one node. - **AC-1 (TIER 1):** `serve_double_sparsity.sh` boots single-node TP=8 with `MODEL_PATH` pinned to `/cluster-storage/models/deepseek-ai/DeepSeek-V3.2` (not the HF-id default, per DEC-6) and the new mask; `/get_server_info` shows DS enabled, TP=8, `kv_cache_dtype=fp8_e4m3`, `page_size=64`, expected radix setting, and the cluster model path; `/generate` returns non-empty text. - **AC-1.1 (TIER 1):** On a prompt longer than `top_k`, `meta_info["double_sparsity"]` shows `0 < sparsity_rate < 1` and `dense_fallback == 0`. `sparsity_rate == 1` or `dense_fallback == 1` fails.
- **AC-1b (TIER 2):** Chunked-prefill probe is run and recorded before the AC-11 sweep; if it fails, chunked-prefill is disabled on BOTH DS and DSA (sidecars show `chunked_prefill_size=-1`) and a follow-up is filed. A mismatched-setting AC-11 set is invalid.
- **AC-6 (TIER 2):** The bundle records REGULAR CUDA-graph capture/replay status (distinct from disabled piecewise) captured at first DS boot — success or a documented exception. Recording only `disable_cuda_graph=False` or only disabled-piecewise is insufficient.
- **AC-8 / AC-9 (TIER 1):** DS run via `benchmark.sh` (AC-8) and DSA baseline via `benchmark_baseline.sh` (AC-9) at matching operating point; smoke uses explicit `TRIALS=1` + shortened `MEASUREMENT_WINDOW_S`, radix-off both sides, labeled non-AC-11. JSONLs + valid `.meta.json` sidecars produced; the hard duration guard refuses sub-window JSONLs; a smoke JSONL presented as AC-11 is rejected.
- **AC-10 (TIER 2):** Both radix fixtures pass (label-capture + FP8 scale-stability), the validator guard is flipped via a ServerArgs/launcher field or state-file/artifact-path contract (NO env override — DEC-5), `--disable-radix-cache` is removed from the final DS launch, and DS boots radix-on. A radix-on boot requiring an env override fails AC-10.
- **AC-11 (TIER 2):** 3-trial DSA+DS sweep at conc 16/32/64, 120s warmup, 600s window, median comparison. DS TPS within 5% of DSA and DS P99 TTFT ≤ 1.10x DSA are DIRECTIONAL targets (a miss is recorded as an AC-11 failure + follow-up, per DEC-7). Radix settings MUST match (comparator refuses a mismatch). Each JSONL duration ≥ 600s with valid sidecars; comparator exits 0 with a TPS/TTFT pass-or-fail summary.
- **AC-12 (TIER 2):** NIAH 4K/16K/64K + MMLU 5-shot via `test_double_sparsity_v32.py`, all gates pass at threshold; any gate below threshold fails the loop4 MVP claim. Optional corrupt-mask / zero-signature negative-sensitivity runs fail loudly.
- **AC-Q (TIER 1):** `test_dsv32_quality_smoke.py` compares DS-on vs DSA on 20 deterministic prompts, single-node sequential (DSA reference captured first, then DS). Four gates: `prefix_match_rate >= 0.80`, `mean_rouge_l >= 0.85`, `niah_mini_recall >= 4/5`, `first_8_tokens_divergence == 0`. Any single gate below threshold fails.
